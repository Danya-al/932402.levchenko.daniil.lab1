## Описание

Страница «О себе» с семантической разметкой и оформлением в тёплой цветовой гамме.

## Структура

- `header` — имя автора, подзаголовок, логотип
- `main` — секции «Навыки» и «Проекты»
- `aside` — любимая кухня
- `section` — форма обратной связи
- `footer` — копирайт

## Использовано

Семантические теги, списки `ul` и `ol`, изображение с атрибутами `src`, `alt`, `width`, `height`, форма с полями `text`, `email` и `textarea`. Цветовая гамма задана через атрибут `style`.
